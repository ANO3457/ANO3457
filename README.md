### Hey, I'm Ahmet 👋

I like building and fixing developer tools—mostly small, reliable things that do one job well without getting in the way.

Most of my time goes into Python, CLI tools, parsers, and tracking down weird edge cases across Linux, macOS, and Windows.

#### What I focus on
- **Developer & Agent Tooling:** CLI utilities, token optimization, and data analysis.
- **Compilers & Shaders:** Shader translation (WGSL, CUDA, HIP).
- **Parsers & Runtimes:** Bytecode instructions and execution safety.
- **Code Analysis:** Tracing architectural decisions in large codebases.

#### How I work
When I fix a bug, I always write a test to reproduce it first before touching any code. I try to keep my PRs small, focused, and predictable—no giant refactors, no breaking changes, and tests that actually pass.

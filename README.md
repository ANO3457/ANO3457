### Hey, I'm Ahmet 👋

I like building and fixing developer tools - mostly small, reliable things that do one job well without getting in the way.

Most of my time goes into Python, TypeScript, CLI tools, parsers, and tracking down edge cases across Linux, macOS, and Windows.

#### What I focus on
- **Developer & Agent Tooling:** CLI utilities, static analysis, and runtime guardrails for AI agents and MCP servers.
- **Compilers & Shaders:** Cross-platform shader translation (WGSL, CUDA, HIP, Metal, HLSL) and AST migration engines.
- **ML & Data Systems:** Training pipelines (Apple Silicon MLX, TRL/ORPO/SimPO) and codebase indexing/search.
- **Testing Infrastructure:** Reproducible regression suites and database test fixtures.

#### How I work
When I fix a bug, I write a test to reproduce it first before touching any code. I keep my PRs small, focused, and predictable - no giant refactors, no breaking changes, and tests that actually pass.
